# MyDay 手机版 PRD

> 把电脑上的 MyDay（本地网页版）改造成安卓手机 App。电脑版在 `D:\App\MyDay`，两边各自独立维护。
> 已确认的四个前提（2026-09-19 凯森选定）：
> 1. **Flutter 原生重写**，不是网页套壳；
> 2. 手机上的数据可以**从电脑导出的备份 zip 导入**，但两边不联网同步；
> 3. 第一版**五个模块全搬**（首页 / 课程 / 天气 / 备忘录 / 设置）；
> 4. 天气**沿用「我的地点」自己选城市**，不申请定位权限。

## 1. 目标

把「打开就知道今天有什么课、天气怎么样、有什么要记的事」这件事搬到手机上，
随时能看、随时能记，**不联网也能用**（除了天气取数），数据只存在这台手机里。

## 2. 与电脑版的差异（重要）

| | 电脑版 | 手机版 |
| --- | --- | --- |
| 运行方式 | Python 本地服务 + 浏览器 | 纯安卓 App，没有服务端 |
| 数据存放 | `D:\App\MyDay\data\*.json` | 手机应用私有目录下的同名 JSON |
| 数据互通 | — | 只能手动：电脑导出 zip → 导进手机（见 6） |
| 交互 | 侧边导航 + 鼠标 | 底部导航 + 触屏，按钮和行高按手指来 |
| 天气取数 | 服务端转发（绕开跨域） | App 内直连 Open-Meteo |
| 交付 | 双击 bat | 一个 APK，自己装到手机上 |

保留不变的部分：零预置原则、每周一套课表、节次全自定义、四份 JSON 的数据结构、
「我的地点」规则、备忘录的保存与收放、导入课表 xlsx 的能力（见 5.5）。

## 3. 零预置原则（不变）

App 里不许出现任何真实个人信息：不预置课表、作息时间、校区、城市、姓名。
首次启动相关模块为空并给引导。测试里继续放禁词表守着。

## 4. 界面结构

底部三个入口（手机竖向），顺序：首页 / 功能 / 设置；课程、天气、备忘录、记账
收进「功能」页里（v1.3.0 起）。
顶部一条标题栏，显示当前页面名 + 今天是第几教学周（右侧胶囊）。

### 4.1 视觉风格（v2.1.1 起：v2.0 设计系统）

所有色值、字号、间距都定在 `lib/ui/design.dart` 里，改外观只改这一个文件。
配套设计稿见仓库外部的 `设计规范.md` / `design-system.css` / `mobile-ui-redesign.html`。

**配色**

- 主色是**靛蓝** `#2B54C8`（按下 `#1F3F9E`，浅底 `#EEF3FF`，描边 `#BCCEFB`）；
  不用高饱和的「链接蓝」
- 强调橙 `#F07A28` 是**稀缺色**，只给「进行中 / 即将开始 / 天气预警」用，
  一屏最多出现 1~2 次，它的稀缺性本身就是信息
- 中性阶带冷调（蓝灰），八档：`ink-900 #0F1420`（主标题）/ `ink-700 #333C52`（正文）/
  `ink-500 #5E6980` / `ink-400 #8A94A8`（辅助）/ `ink-300 #B4BCCB`（占位、已结束）/
  `ink-200 #E2E6EE`（分隔线）/ `ink-100 #EDF0F5` / `ink-50 #F4F6FA`（页面底）
- 语义色只用于图标着色，不用于文字：成功 `#0E9B5F`、警告 `#C78413`、
  危险 `#D63B3B`（只给「清除数据」）
- 深色模式**不用纯黑**：底 `#131720`、卡片 `#1C2230`，层级靠 1px 边框而不是阴影

**字号**（收敛版 1.2 比例，7 档）

40 display（只有天气大温度）/ 26 h1（页面主标题）/ 20 h2（强调卡标题）/
16 h3（列表项标题、卡片小标题）/ 14 body（正文，行高 1.55）/ 12.5 sm（辅助说明）/
11 xs（标签、角标、时间）

- 字重只用 400 / 500 / 600 / 700（中文不用 300，渲染发虚）
- 中文行高比西文松：正文 1.55，标题 1.15~1.35
- 数字一律等宽（`tabular-nums`），切换值时不会左右跳

**布局与形状**

- 8pt 栅格：间距只取 4/8/12/16/20/24/32；页面左右安全边距 16
- 圆角四级：10 / 14 / 18 / 24（卡片统一 **14**）
- 阴影极浅、多层、冷调（`Sh.sm`）；深色下阴影几乎不可见，改用边框分层
- 底部导航：白底（88% 半透明 + 背景模糊）+ 顶部 1px 描边，高 60；选中项靠
  **色彩 + 顶部 3px 指示条**表达，不用整块蓝底
- 可点区域最小 44×44；卡片按下 `scale(.975)`，缓动 `cubic-bezier(.32,.72,0,1)`
- 动效克制：主卡入场是「淡入 + 上移 10px / 500ms」且**只跑一次**；
  不要做无限循环动画（会让 `pumpAndSettle()` 永远等不到静止、测试超时）

**逐页结构**

- 首页：页头（日期 + 问候语 + 周次胶囊）→ 三栏状态条 → 正在上课主卡 →
  天气/备忘双列小卡 → 今日课程时间轴 → 备忘录速览
- 功能页：大标题页头 → 2×2 功能宫格（图标 + 说明 + 一条关键数据）→ 快捷操作
- 课程页：周切换（大箭头 + 直接选周）→ 横向日期条 → 日/周/列表分段 →
  课表（课块低饱和底色 + 左侧 3px 色条，空格子只留格线）→
  底部操作（「添加课程」是主按钮）
  （课表保持「整张表一起平移 + 双指缩放」，不做固定左列 —— 见 DEV-PLAN 的回退记录）
- 天气页：靛蓝主卡（40px 温度 + 预警条）→ 24 小时折线 → 详情 2 列网格 →
  未来 7 天 → 我的地点
- 设置页：账号卡 → 分组（通用 / 数据 / 危险操作），每组一张卡、行内带图标与值
- 图标一律线性图标，**不用 emoji 或 ★ 这类符号充当图标**

- **首页**：今日课程、今日天气的紧凑卡片；备忘录速览（标题 + 小三角收放，展开看正文或清单）。
- **课程**：周次选择器（左右箭头 + 周次），课表用表格；点课块改；右下角悬浮按钮加课；
  顶部菜单里放「复制本周到其他周 / 清空本周 / 导入课表」。
- **天气**：城市下拉 + 刷新；实况、24 小时、7 天；失败降级（缓存 + 标注时间）。
- **备忘录**：两段式——列表页（分组 + 搜索）→ 点进详情页编辑；详情页底部是
  「保存 / 置顶 / 归档 / 删除」。
- **设置**：基本（称呼、学期名、第 1 周周一、每周起始日、校区）、外观、
  作息与节次、我的地点、数据（备份导出 / 从备份导入 / 打开数据目录 / 清空）。

## 5. 各模块要点

### 5.1 课程
- 数据结构和电脑版完全一致：`{version, weeks: {"3": [lesson...]}}`，lesson 含
  id / day / slot / spanEnd / name / location / teacher / note / color。
- 每周一套、各周独立、整周复制（覆盖 / 合并 / 只填空的周）。
- 节次由用户在设置里自定义，删被占用的节次要提示三种处理。
- 导入课表：读教务系统导出的 xlsx，先预览再导入（解析规则照搬电脑版，见 5.5）。

### 5.2 天气
- 数据源 Open-Meteo（免 key）：forecast + geocoding。
- 「我的地点」：搜索添加、下拉切换、逐条移除，删当前城市顺位到第一个。
- 缓存到 `weather_cache.json`，断网时用旧数据并标注「旧数据」。
- 自动刷新间隔可设（10 / 30 / 60 分钟 / 仅手动）。

### 5.3 备忘录
- 两种形态：笔记（多行文本）/ 清单（可勾选）。
- 编辑即自动保存 + 底部「保存」键（和电脑版一致），状态提示「已保存 / 有改动…」。
- 置顶、搜索（标题 + 正文 + 清单项）、归档。
- 列表第二行显示「类型 · 摘要」，不显示「未分类」这类占位词。

### 5.4 首页
- 今日课程按时间排序，标出已上 / 正在上 / 下一节。
- 今日天气紧凑卡片。
- 备忘录速览：最多 3 条，清单项可直接勾，正文/清单可收放。

### 5.5 导入课表（xlsx）
- 认得的表格形状与电脑版一致：第 3 行表头（时间 | 节次 | 星期一…星期日），
  课程格内容 `课程名称(考核方式)(课程类别)专业班级{周次范围 教师 教室}`，
  一格可能两门课，课程格常按两节纵向合并，合并区的值可能被存了多遍。
- 先用预览（不写数据），确认后按每门课的周次范围铺到对应周；追加 / 覆盖二选一。
- xlsx 是 zip + XML，Dart 里用 `archive` 包解压后自己解析 XML。

### 5.6 设置与数据
- **检查更新**（v2.1.1）：关于卡里手动查，数据源是 GitHub Releases。
  只认 `mobile-v` 前缀的 tag（仓库里还有电脑版的 release，不能撞上）。
  有新版弹窗：新版本号 + 发布说明 + 「去下载」（系统浏览器打开 apk 附件）。
  **只在手动点的时候查**，不做后台自动检查，也不内置下载器。
- **备份导出**：打一个 zip（四份 JSON + 版本号 + 导出时间），存到手机可访问的位置。
- **从备份导入**：选 zip 还原，导入前先自动留一份当前的。
- **兼容电脑版备份**：电脑版导出的 zip 结构相同，要能直接吃（见 6）。
- 清空全部数据：先强制备份 + 二次确认。

## 6. 数据搬家（电脑 → 手机）

1. 电脑版设置页点「立即备份」，得到一个 `MyDay-backup-*.zip`；
2. 把这个 zip 传到手机（微信 / QQ / 数据线都行）；
3. 手机版设置页点「从备份导入」，选中这个 zip，确认后覆盖。

两边备份包的目录结构和字段名必须严格一致，这样才互相认得。为此手机版
**不新增、不改名任何 JSON 字段**，只在文件里加一个来源标记。

## 7. 第一版不做的

- 云同步、账号、登录（继续不做）。
- 定位权限自动取天气（第一版不用，只留「我的地点」）。
- 小组件、通知提醒、闹钟。
- iOS（这台 Windows 机器只能出安卓包）。
- 应用商店上架（自己装 APK）。
